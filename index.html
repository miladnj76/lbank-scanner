روش امتیازدهی

ترکیب انفجار: حجم غیرعادی + قیمت نسبتاً کم‌تحرک + بیس فشرده. دود: حجم بالا و عقب‌ماندگی قیمت. رادار: رشد حجم و شروع حرکت. فقط ۸۰ بازار پرحجم‌تر برای دریافت کندل بررسی می‌شوند تا فشار درخواست‌ها کمتر باشد.

اگر مرورگر دسترسی API را به‌دلیل CORS یا شبکه مسدود کند، خطا نمایش داده می‌شود؛ نسخه بدون سرور نمی‌تواند این محدودیت را دور بزند.

صفحه باید باز و فعال بماند. iOS ممکن است با قفل صفحه یا رفتن به برنامه دیگر اسکن را متوقف یا کند کند. هیچ سفارش معاملاتی ارسال نمی‌شود.
